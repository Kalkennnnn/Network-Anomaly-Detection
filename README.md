# Обнаружение сетевых аномалий методами машинного обучения

Десктопное приложение с графическим интерфейсом, которое классифицирует сетевые потоки как **BENIGN** (нормальный трафик) или **ATTACK** (атака). Работает в двух режимах: захват трафика с сетевого интерфейса в реальном времени и офлайн-анализ PCAP-файлов.


## Возможности

- **Два режима:** онлайн-захват с сетевого интерфейса и офлайн-анализ PCAP-файлов
- **Журнал событий:** все обнаруженные атаки логируются с временными метками и IP-адресами
- **Многопоточность:** захват и классификация идут в фоне, интерфейс не зависает
- **Цветовая индикация:** зелёный — BENIGN, красный — ATTACK
- **Прогресс-бар** при анализе PCAP, результаты появляются сразу, не дожидаясь конца файла

## Как это работает

1. Из сетевого трафика собираются потоки (flows) и считаются их статистические признаки.
2. Признаки нормализуются так же, как при обучении.
3. Обученная модель Random Forest классифицирует каждый поток.
4. Результат выводится в таблицу и журнал событий.

Анализ идёт по статистике потоков, а не по содержимому пакетов, поэтому подход применим и к зашифрованному трафику.

## Данные и модель

Обучение проводилось на датасете [CIC-IDS2017](https://www.unb.ca/cic/datasets/ids-2017.html): 2 830 743 записи, 15 типов трафика, 83 признака.

**Предобработка:**

| Этап | Результат |
| --- | --- |
| Удаление дубликатов | 2 830 743 → 2 522 362 записи |
| Удаление идентификаторов и константных признаков | остался 68 признаков |
| Обработка Inf/NaN | 3 128 записей |
| Нормализация | μ = 0, σ = 1 |
| Разбивка train/test | 80 / 20 |
| Балансировка | undersampling |

**Отбор признаков** в два этапа:

1. Важность по Random Forest (MDI) — оставлен топ-20 признаков (75,8% предсказательной силы).
2. Корреляционный анализ Пирсона — удалены признаки с |r| > 0,95, осталось **10 финальных**:

`Bwd Packet Length Std`, `Average Packet Size`, `Packet Length Variance`, `Total Length of Bwd Packets`, `Fwd IAT Std`, `Total Length of Fwd Packets`, `Fwd Packet Length Max`, `Fwd Packet Length Mean`, `Flow IAT Max`, `Fwd Header Length`
